# 260903 딱지원핏 통합 수정 백로그

## 작업 원칙

- 현재 검증 중에는 오류를 건별로 즉시 수정하지 않는다.
- 실제 사용자 흐름을 끝까지 재현하고 실패 화면·재현 조건을 먼저 수집한다.
- 검증이 끝난 뒤 아래 항목을 한 번에 수정하고 전체 흐름을 다시 녹화한다.
- 결제는 이미 완료되었으므로 재결제하거나 결제 여부를 반복 확인하지 않는다.
- 관리자 계정은 결제·주문번호 입력 없이 Word와 발표자료까지 검증할 수 있어야 한다.

## 목표 사용자 흐름

1. 공고문·작성 양식 업로드 및 사업 설명
2. 증거가 부족해도 현재 답변으로 검증용 1차 초안 생성
3. 부족한 증거, 보충 방법, 반영할 목차를 구체적으로 안내
4. 사용자가 새 자료를 올리면 `새 자료 반영해 초안 다시 만들기` 실행
5. 같은 공고·아이템·양식에서 최대 3회의 묶음 수정 제공
6. 최종 Word 생성
7. 같은 내용으로 발표자료 생성

## 결제·권한·복귀 UX

- 그로블 결제 완료 후 딱지원핏 랜딩페이지가 아니라 주문번호 확인 단계가 바로 보여야 한다.
- 그로블 결제 완료 화면에서 주문번호를 복사하라고 명확히 안내해야 한다.
- 딱지원핏 복귀 직후 주문번호 입력창과 확인 버튼이 바로 보여야 한다.
- 관리자 로그인 상태에서는 결제 버튼과 주문번호 입력을 건너뛰고 관리자 권한 완료 상태를 보여야 한다.
- 일반 사용자 결제 흐름과 관리자 우회 흐름을 각각 회귀 테스트한다.

## 초안·증거 UX

- 기관 추천서, 시장 근거, 인터뷰, 계약서 등이 없어도 검증용 초안은 생성한다.
- 확인되지 않은 내용은 `[확인 필요]`, `[증빙 필요]`, `[추천기관 협의 및 추천서 확보 필요]`처럼 표시한다.
- 증거가 없다는 이유로 같은 자료를 반복해서 요구하거나 초안 생성을 막지 않는다.
- `무슨 자료를`, `어디서`, `어느 목차에` 보충할지 안내한다.
- 실제 제출 필수자격 미충족 경고와 초안 생성 가능 여부를 분리한다.

## 현재 재현된 오류

- 공식 시장·경쟁 검색 실패 메시지가 반복 노출된다.
- 검색 실패 뒤 사용자 제공 사실과 계획으로 초안을 이어간다는 안내는 나오지만 후속 단계가 안정적으로 완료되지 않는다.
- 초안 모의심사 응답을 끝까지 읽지 못했다는 오류가 발생한다.
- 묶음 수정 요청이 실패하며, 실패 시 수정 횟수는 차감되지 않는다고 표시된다.
- 생성 실패 메시지가 누적되어 사용자는 결제했는데 아무 결과도 못 받는 것으로 느낀다.
- 동일 대화에 초안 결과가 남아 있어도 하단에 `현재 내용으로 사업계획서 초안 만들기`가 다시 노출되어 상태가 혼란스럽다.
- 초안 결과·모의심사·최종 Word 잠금 상태의 연결이 불명확하다.
- 라이브 화면에서는 최종 Word와 발표자료까지 한 번에 완료되지 않는다.

## 최종 일괄 수정 시 확인할 기술 항목

- 시장·경쟁 검색 실패 시 사용자 근거 기반 대체 경로가 초안 생성을 계속 완료하는지
- LLM 응답 잘림·비 JSON 응답에서도 감사와 수정 결과가 복구되는지
- 초안 생성 상태가 중복 실행 버튼과 충돌하지 않는지
- 새 자료 추가 시 기존 초안을 보존하고 수정 대기 상태로 전환되는지
- 수정 성공 시에만 3회 수정권을 차감하는지
- 관리자 권한이 초안·Word·발표자료 모든 API와 화면에서 일관되게 적용되는지
- Word와 발표자료가 동일한 최신 초안·근거 상태를 사용하는지
- 실패 메시지를 하나의 이해 가능한 안내로 정리하고 재시도 지점을 명확히 보여주는지

## 녹화 기준

- 코덱스 대화 화면이 아니라 딱지원핏 브라우저 화면만 녹화한다.
- 현재 검증 녹화에는 발생한 오류와 재현 순서를 그대로 남긴다.
- 일괄 수정 뒤 최종 녹화는 `관리자 권한 확인 → 1차 초안 → 증거 보충 안내 → 새 자료 반영 수정 → Word → 발표자료` 전 과정을 포함한다.

## 현재 산출물 상태

- 2026-09-03 관리자 실사용으로 딱지원핏 라이브 화면의 `초안 → 모의심사 → Word → 발표자료 → PPTX/PDF` 전체 흐름을 완료했다.
- 사업계획서 DOCX는 실제 브라우저 다운로드 뒤 OOXML 압축 무결성 검사를 통과했다.
- 발표자료는 화면에서 12장·7분 발표 원고와 예상 질문 5개를 생성했고, 다운로드 파일에는 부록을 포함해 PPTX 15장·PDF 15쪽이 들어 있다.
- 미확인 4대 과학기술원 추천서·정부사업 이력·체납 여부는 초안과 발표자료에 확인 필요 항목으로 남기되 파일 생성을 막지 않는다.
- 관리자 화면에 `관리자 검증 모드 · 결제 생략`을 표시하고, 초안·Word·발표자료 API에서도 동일한 관리자 권한을 사용한다.
- 검토용 Word/PPTX 다운로드는 첫 최종본 제공일과 수정 가능 기간을 시작하지 않는다. 제출용 최종본을 받을 때만 수정 기간을 시작한다.
