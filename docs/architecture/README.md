# 딱지원핏 요구사항과 시스템 설계

작성일: 2026-09-17. 사용자가 선택한 범위는 기존 딱지원핏을 기반으로 설계를 정리하고 필요한 기능을 보강하는 것이다.

## 이번 구현

기존 지원사업 탐색·자격 확인·Word·발표자료·결제 흐름을 재사용하고 `/operations` 관리자 운영 화면을 추가했다. 월 목표, 일자별 누적 성과, 영상 계획을 서버에 저장하고 남은 매출·주문·기간을 계산한다. 수치는 운영자가 결제 원본과 채널 통계를 확인해 기록하며 외부 통계 자동 수집은 아직 연결하지 않았다.

운영 저장소는 기존 Upstash Redis를 사용한다. 요청 검증, 서버 관리자 권한, 원자적 버전 비교 저장, 변경자·시간 기록, 오류 응답, 로컬 실행, 단위·API 검사, 배포 빌드를 갖춘 모듈이다. 로컬 실행은 별도 파일 저장소를 사용해 운영 계정·주문을 변경하지 않는다.

## 상태 구분

- **기존 본체:** 운영 중인 코드와 로컬 변경을 읽고 재사용했다. 이 작업에서 본체 전체의 실결제·AI 생성·환불을 다시 실행하지 않았다.
- **이번 운영 모듈:** 로컬에서 실제 저장·재조회 가능한 구현. 프로덕션 빌드에는 포함되며 운영 도메인에는 배포하지 않았다.
- **설계만 있는 확장:** YouTube/GA4 자동 수집, 주문과 캠페인의 자동 연결, 관계형 주문 원장, 장시간 작업 큐. 구현된 기능으로 표시하지 않는다.

기존 저장소의 진행 중인 변경 22개를 별도 작업본에 복사했다. 원본 저장소의 파일을 수정하거나 기존 변경을 취소하지 않았다. 현재 작업본은 이 변경들을 포함하므로 운영 배포 전에 전체 후보 변경을 함께 검토해야 한다.
