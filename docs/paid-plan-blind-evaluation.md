# 유료 사업계획서 블라인드 비교 운영안

## 목적

새 근거·전략·도식 파이프라인이 기존 작성 방식보다 실제로 나은지 다음 세 지표로 확인한다.

1. 심사 적합성
2. 사실 일치율과 출처 추적 가능성
3. 제출 가능 상태까지 이용자가 들인 수정시간

선정 여부는 경쟁률·평가위원·예산 등 외부 요인의 영향을 크게 받으므로 1차 제품 품질 지표로 쓰지 않는다.

## 표본

- 실제 제출 유형을 반영한 10건 이상을 사용한다.
- 예비창업, 초기창업, 소상공인, 기술개발 등 서로 다른 공고를 섞는다.
- 같은 사용자 원답변·첨부자료·공고문·공식 양식으로 기존 방식(A)과 새 방식(B)을 각각 생성한다.
- 새 결제 고객에게 품질이 낮을 수 있는 A를 무작위 제공하지 않는다. 기존 자료나 사전 동의한 내부 QA 표본으로만 비교한다.

## 익명화와 무작위화

1. 대표자명, 상호, 연락처, 거래처명, 문서 메타데이터를 제거한다.
2. A/B 표시와 생성 시각을 지우고 각 파일에 무작위 6자리 평가번호를 부여한다.
3. 한 쌍의 제시 순서를 무작위로 바꾼다.
4. 번호와 작성 방식의 대응표는 평가를 하지 않는 운영자 1명만 보관한다.

## 평가자와 채점

- 정부지원사업 사업계획서 검토 경험이 있는 평가자 2명이 서로 독립적으로 채점한다.
- 평가자는 어느 파일이 새 방식인지 알 수 없어야 한다.
- 아래 항목을 각 1~5점으로 평가하고, 사실 오류가 하나라도 있으면 별도로 기록한다.

| 항목 | 확인 질문 |
|---|---|
| 공식 양식 적합성 | 공고의 목차·평가항목·제출 요구에 맞는가 |
| 사업 논리 | 문제→해결→고객→수익→실행이 끊김 없이 이어지는가 |
| 사실 일치 | 원답변·첨부자료에 없는 수치·성과·계약을 만들지 않았는가 |
| 경쟁우위 | 가까운 경쟁대안 2곳과 같은 기준으로 비교했는가 |
| 출처 추적 | 시장·경쟁 주장에 URL·확인일·근거가 연결되는가 |
| 도식 유용성 | 근거 있는 도식만 A4 문맥에 배치됐는가 |
| 수정 용이성 | 제출 가능 상태까지 사용자가 고칠 범위가 명확한가 |

## 사용자 시간 측정

- 최초 작성 시작부터 최종 Word 다운로드까지 걸린 시간을 기록한다.
- 그중 AI 대기시간과 사용자가 자료를 찾고 입력한 시간을 분리한다.
- 묶음 수정 횟수, 업로드한 보완자료 수, 최종 차단 사유를 함께 기록한다.

## 통과 기준

다음 조건을 모두 만족할 때만 새 방식이 개선됐다고 판단한다.

- B가 심사 적합성·사실 일치·출처 추적의 평균에서 A보다 높다.
- B의 중대한 사실 오류율이 A보다 높지 않으며 목표는 0건이다.
- B의 사용자 수정시간 중앙값이 A보다 짧거나, 늘어난 시간이 사실 오류 감소로 설명된다.
- 평가자 2명의 선호가 엇갈린 표본은 승패로 세지 않고 원인을 재검토한다.

## 첫 실결제 테스트 체크리스트

첫 결제 1건에서는 우선 아래만 확인한다.

- 결제 인증과 동일 공고·아이템·양식 연결
- 근거 검색 URL·확인일과 가까운 경쟁사 2곳 표시
- 근거 부족 시 최종 Word 차단 및 자료 추가 안내
- 근거가 충분한 도식만 최대 6종 선택·목차 자동배치
- 필수 확인 4개를 읽고 체크한 뒤 최종 Word 다운로드
- 최초 다운로드 뒤 30일·묶음 수정 3회 표시와 성공한 수정만 차감
- 주문별 실제 AI 원가 누적과 비정상 폭주 방지선 작동

한 건의 성공은 품질 효과를 입증하지 않으며, 위 블라인드 표본 평가와 별도로 기록한다.
